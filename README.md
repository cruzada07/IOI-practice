# Ejercicios resueltos de IOI

Colección de ejercicios y soluciones desarrolladas durante mi práctica para
**IOI (International Olympiad in Informatics)** y programación competitiva.

La idea de este repositorio es documentar mi progreso, practicar algoritmos
y estructuras de datos, y mantener organizadas las soluciones a los problemas
que voy resolviendo.

---

## Contenido

Actualmente, el repositorio contiene ejercicios relacionados con:

- Algoritmos
- Estructuras de datos
- Búsqueda y ordenamiento
- Programación dinámica
- Grafos
- Técnicas de optimización
- Resolución de problemas

El contenido se irá ampliando conforme avance con la práctica.
